# LLM Inference Stack Documentation

This portal is the centralized entry point for platform documentation.

It consolidates:

- curated navigation by domain;
- generated reference material for API, configuration, feature flags and profiles;
- release-oriented versioning through MkDocs + `mike`.

The migration is incremental. During the transition, some detailed source material still originates from the legacy `docs/` tree and is synchronized into this site during build.
