# Evals: v1.10.0-agentic-runtime

## Posture

- `AGENT_EVALS_ENABLED=false`
- `AGENT_PRODUCTION_REQUIRES_EVAL_BASELINE=true`

## Included Surface

- Eval suite creation
- Eval run execution
- Baseline registration
- Admin UI visibility for eval status

## Release Interpretation

Evals are integrated in this release, but they remain opt-in. Production-grade activation is expected to keep an eval baseline requirement once operators enable the runtime.
