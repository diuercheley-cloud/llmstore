# Exemplo AnythingLLM

Configuração para AnythingLLM:

1. No AnythingLLM, vá em **Settings** > **LLM Preference**.
2. Selecione **Generic OpenAI**.
3. URL: `http://localhost:18080/v1`
4. Key: `demo-default`
5. Selecione o modelo disponível na lista.

Para Embeddings:
1. Em **Embedding Preference**, selecione também **Generic OpenAI**.
2. URL: `http://localhost:18080/v1`
3. Key: `demo-default`
