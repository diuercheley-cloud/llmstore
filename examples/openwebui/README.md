# Exemplo Open WebUI

Para usar com Open WebUI:

1. Inicie o Open WebUI (Docker ou nativo).
2. Acesse **Settings** > **Connections**.
3. Em **OpenAI API**:
   - URL: `http://localhost:18080/v1` (ou `http://host.docker.internal:18080/v1` se em Docker)
   - Key: `demo-default`
4. Clique no botão de atualizar modelos.
5. Selecione o modelo na interface de chat e comece a conversar.
