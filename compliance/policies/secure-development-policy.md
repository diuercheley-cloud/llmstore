## 1. Diretrizes
- Todo código deve passar por code review antes do merge.
- Vulnerabilidades devem ser escaneadas em cada build de CI.
- Ambientes de desenvolvimento, teste e produção devem ser segregados.
- Segredos nunca devem ser armazenados no código-fonte.
