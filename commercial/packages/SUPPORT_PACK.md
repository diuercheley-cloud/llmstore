# Support & Maintenance Pack

## Scope
Ongoing technical support, software updates, and performance tuning for the LLM Inference Stack.

## Requirements
- Active license for any Enterprise/Sovereign pack

## Inclusions
- 24/7 Priority Support (Email/Slack/Phone)
- Monthly Health Checks
- Performance Tuning Sessions
- Beta access to new models/features
- Patch management for Control/Data planes

## Exclusions
- First-level user support (unless Tier 1 included)
- Third-party model fine-tuning (unless specified)

## Prerequisites
- Remote access agreement (if troubleshooting required)
- Customer technical contact identified

## SLA/SLO (Suggested)
- Ticket Triage: < 30 mins
- Root Cause Analysis: < 3 days

## Checklist de Entrega
- [ ] Support Portal Access Created
- [ ] Emergency Contact List Exchanged
- [ ] First Monthly Review Scheduled

## Critérios de Aceitação
- Response times meet contract obligations
- All security patches applied within 48h of release

## Riscos
- Knowledge gap in customer team
- Incompatible hardware changes by customer

## Matriz RACI
- Bug Fixing: Provider (R)
- Monitoring: Customer (A), Provider (R)
- Escalation: Customer (R)
