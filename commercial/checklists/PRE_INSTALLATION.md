# Pre-Installation Checklist

- [ ] GPU Drivers (NVIDIA/AMD) installed and verified.
- [ ] Docker and Docker Compose (v2.x) available.
- [ ] Network Ports (443, 6443, 8000) open in firewall.
- [ ] Customer OIDC details (Client ID, Secret, Discovery URL) received.
- [ ] Storage volume (min 500GB) provisioned for model cache.
- [ ] SSL/TLS Certificates (or Root CA) ready for import.
- [ ] Hardware Attestation compatibility confirmed (if required).
