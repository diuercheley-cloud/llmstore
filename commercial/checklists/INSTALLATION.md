# Installation Checklist

- [ ] Control Plane environment variables configured (`.env`).
- [ ] `docker-compose up -d` executed successfully.
- [ ] Database migrations applied (`alembic upgrade head`).
- [ ] Data Plane nodes registered and in 'Healthy' state.
- [ ] PKI trust established between Control and Data planes.
- [ ] Admin user account created and login verified.
- [ ] Initial model weights downloaded/verified.
