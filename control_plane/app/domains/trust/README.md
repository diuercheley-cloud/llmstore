# Trust Domain

Este dominio descreve a superficie contratual do plano de trust.

- `allowed_inputs`: atestacoes, provas, material criptografico e sinais de integridade.
- `emitted_events`: receipts, verificacoes e alertas de violacao.
- `forbidden_dependencies`: dominios que nao devem virar dependencias obrigatorias.
- `deterministic_requirements`: garantias para verificacao local e reproducao deterministica.

Nenhum codigo existente e movido neste passo.
