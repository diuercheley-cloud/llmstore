API Reference

A API do LLM Inference Stack é compatível com o protocolo da OpenAI, facilitando a integração com ferramentas e bibliotecas existentes.

Autenticação

Todas as requisições devem incluir sua API Key no cabeçalho Authorization usando o prefixo Bearer.

Header
Authorization: Bearer sk-local-...

Chat Completions

POST /v1/chat/completions

Gera uma resposta para uma lista de mensagens.

cURL

bash 
curl http://localhost:18080/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "default",
    "messages": [{"role": "user", "content": "Olá!"}]
  }'

Python (requests)

python 
import requests

url = "http://localhost:18080/v1/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {
    "model": "default",
    "messages": [{"role": "user", "content": "Olá!"}]
}

response = requests.post(url, headers=headers, json=data)
print(response.json()["choices"][0]["message"]["content"])

JavaScript (fetch)

javascript 
const response = await fetch("http://localhost:18080/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "default",
    messages: [{ role: "user", content: "Olá!" }]
  })
});

const data = await response.json();
console.log(data.choices[0].message.content);
