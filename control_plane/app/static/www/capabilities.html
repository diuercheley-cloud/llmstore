Limitacoes (fora do escopo nesta versao)

  • PSP real nao incluido — Nao ha integracao com Stripe, Asaas ou similar. O faturamento e manual.
  • PIX real nao incluido — Nao ha geracao de QR Code PIX ou cobranca automatica via banco.
  • Tools / Function Calling parcial — Suporte limitado, depende do backend e modelo local.
  • Modelos dependem do hardware local — Qualidade e performance variam conforme GPU/CPU disponivel.
  • HTTPS opcional em localhost — Por padrao a demo usa HTTP. Producao deve configurar TLS via Caddy.
  • Nao prometemos seguranca absoluta — Relatorios de readiness e security sao insumos, nao substituem auditoria.
