Atualize APIs dos providers sem editar `.env.local` na mão.

Esta tela grava credenciais em `.env.local`, recarrega a configuração do processo e atualiza o registry de providers. As chaves atuais nunca voltam em plaintext. Para trocar uma chave, informe um novo valor. Para remover, marque a limpeza explícita.
