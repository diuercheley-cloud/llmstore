Este laboratório permite validar a conexão com a API OpenRouter, listar modelos autenticados e mapear qualquer modelo para um alias local no gateway.

Dicas

  • O backend "openrouter" deve estar ativo em Configurações de Provedores.
  • Se a chave OpenRouter ficar vazia, os testes usam a chave configurada no backend.
  • O teste configura automaticamente o Model Registry e o Model Backend Route.
  • As requisições passam pelo seu gateway local (18080) e são encaminhadas ao OpenRouter.
