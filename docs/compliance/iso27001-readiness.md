# ISO 27001 Readiness Guide

A stack suporta a implementação de um ISMS (SGSI) aderente à ISO 27001:2022.

## Gestão de Ativos (A.8)
- Inventário automático de modelos, nós de runtime e infraestrutura gerenciada.

## Criptografia (A.10)
- Gerenciamento de chaves via PKI integrada.
- Assinatura de artefatos de release.

## Segurança nas Operações (A.12)
- Proteção contra malware (via container scans no CI).
- Registro de eventos e monitoramento.

## Relacionamento com Fornecedores (A.15)
- Auditoria de supply chain via SBOM (Software Bill of Materials).
