# Documentation Archive

This directory stores material that is not part of the supported documentation surface.

- `releases/`: versioned release notes, release checklists, and cleanup records kept for historical reference.
- `deprecated/`: documents for flows that are no longer supported.
- `duplicates/`: superseded copies replaced by canonical docs elsewhere in `docs/`.
- `orphaned_doc_*.md`: previously archived unowned material kept only to preserve history.
