# Developer Portal

The Developer Portal is the central hub for builders on the Agentic AI Platform.

## Features
- **API Key Management**: Generate, rotate, and revoke keys for agentic and inference workloads.
- **SDK Documentation**: Access guides and API references for building with our platform.
- **Agent Templates**: Start from pre-built templates like support triage or compliance monitoring.
- **Plugin Marketplace**: Upload and manage custom plugins.
- **Testing Console**: Interactive environment for dry-running agent logic and tool interactions.

## Getting Started
Access the portal in the Admin UI under the **Developers** tab.
