# Production Code Interpreter Sandbox

This document describes the production-ready configuration and security posture of the Agent Code Interpreter.

## Overview
The Code Interpreter allows agents to execute arbitrary Python code in a highly isolated environment. In production, this isolation is enforced through MicroVMs or hardened containers.

## Feature Flags
- `AGENT_CODE_INTERPRETER_ENABLED=true`: Enables the code interpreter feature.
- `AGENT_CODE_SANDBOX_PROVIDER`: Choices are `docker`, `gvisor`, `firecracker`, or `mock` (development only).
- `AGENT_CODE_SANDBOX_MICROVM_REQUIRED=true`: Forces execution to use gVisor or Firecracker.
- `AGENT_SANDBOX_ALLOW_SIMULATED_PROVIDER=false`: Prevents fallback to `mock` in production.
- `AGENT_CODE_SANDBOX_NETWORK_ENABLED=false`: Disables network access from within the sandbox.

## Security Constraints

### 1. Code Validation
All code is parsed into an AST and validated against a strict policy:
- **Forbidden Modules**: `os`, `subprocess`, `requests`, `socket`, `sys`, etc. are blocked.
- **Forbidden Calls**: `exec()`, `eval()`, `open()`, `getattr()`, `setattr()`, etc. are blocked.
- **Path Protection**: Access to sensitive paths like `.env`, `/etc/passwd`, `/proc` is blocked.
- **Network Blocking**: Literal URLs and metadata endpoints (e.g., `169.254.169.254`) are detected and blocked.

### 2. Runtime Isolation
- **Docker**: Uses `--network=none`, `--read-only`, and drops all capabilities.
- **gVisor**: Uses `runsc` runtime for kernel-level isolation.
- **Firecracker**: Provides MicroVM isolation (requires KVM).

### 3. Resource Limits
Default limits are enforced per execution:
- **Timeout**: 10 seconds.
- **Memory**: 256 MB.
- **Output**: 64 KB (truncated if exceeded).
- **Disk**: Limited writable `/tmp`.

### 4. Artifact Sanitization
Files generated by the sandbox are scanned for secrets (API keys, tokens) before being allowed as persistent artifacts.

## Attestation
Every execution produces a cryptographic attestation record signed by the platform. This record includes:
- Provider and isolation level.
- Exact code executed.
- Resource limits applied.
- Hashes of generated artifacts.

Verification of this attestation is mandatory in production environments.
