# Agent Capability Catalog

The Capability Catalog is the central registry for all connectors, MCP servers, and plugins.

## Features
- **Governance**: Every entry requires a manifest, version, and owner.
- **Approval Workflow**: Capabilities must be reviewed and approved by an administrator before being available for production use.
- **Risk Assessment**: Entries are categorized by risk and side-effect levels.
- **Trust Reports**: Automated and manual scans generate trust scores and findings for each entry.

## Installation
Entries can be installed and enabled/disabled per tenant. Rollback to previous versions is supported through the versioning system.
