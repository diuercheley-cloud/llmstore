# Marketplace Publication Policy

## Overview

All agents published to the official marketplace must undergo a security and quality review process.

## Review Criteria

1.  **Tool Permissions**: Agents requesting dangerous tools (e.g., shell access, arbitrary DB writes) undergo manual scrutiny.
2.  **Memory Policy**: Verification that data retention and isolation rules are correctly defined.
3.  **Evaluation Baseline**: Proof of performance against a standard evaluation suite.
4.  **Metadata**: Accurate description, documentation, and author information.

## Statuses

- **`pending`**: Bundle uploaded, awaiting review.
- **`approved`**: Review passed, bundle ready for publication.
- **`rejected`**: Bundle failed review. Notes will be provided to the publisher.
