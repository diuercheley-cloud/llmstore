# Support Model

## Support Tiers
- **Tier 1 (Customer Internal):** Basic usage questions, password resets.
- **Tier 2 (Provider Technical):** Configuration issues, bug reports.
- **Tier 3 (Provider Engineering):** Core engine fixes, custom features.

## Incident Severity
- **S1 (Critical):** Complete system outage.
- **S2 (High):** Major functionality impaired (e.g., specific model down).
- **S3 (Medium):** Minor issues, documentation gaps.
- **S4 (Low):** Feature requests, general questions.
