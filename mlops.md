# MLOps & Fine-Tuning

## Overview
End-to-end framework for model fine-tuning and experiment tracking.

## Features
- Data versioning & artifacts management.
- Model lineage and A/B/Canary integration.
- Extensibility for MLflow / W&B.

## Governance
Disabled by default (`MLOPS_ENABLED=false`). Does not require paid tiers of SaaS tracking tools.
